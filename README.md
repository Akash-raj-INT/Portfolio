# 🎮 Akash Raj — 3D Interactive Portfolio

An interactive, retro-futuristic 3D portfolio inspired by the iconic **Super Mario 64 Title Screen**, built with WebGL, Three.js, and modern vanilla web technologies.

---

## 🌟 Live Demo & Highlights

- **3D WebGL Canvas**: Real-time vertex pinch & stretch physics on 3D Mario head using Three.js and custom shaders.
- **Mario Shaders**: Switch between Classic, Metal Mario, Gold Trophy, and Neon Cyber Wireframe materials on the fly.
- **Retro Audio Engine**: Procedural 8-bit sound effects (coin, jump, boing) and retro synth background audio via the Web Audio API.
- **Interactive Project Modals**: Deep-dive project previews with architecture highlights, tech stacks, and live demo links.
- **EmailJS Contact System**: Working contact form connected to EmailJS with real-time feedback, status alerts, and fallback email options.
- **Direct Resume Access**: Quick-access link to the official Google Drive resume folder along with an on-page curriculum vitae preview.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3
- **3D & Graphics**: Three.js (r128), OrbitControls, WebGL
- **Animations**: GSAP, ScrollTrigger, Canvas Confetti
- **Audio**: Web Audio API (custom sound engine)
- **Email**: EmailJS Browser SDK v4
- **Icons**: Lucide Icons

## 💻 Local Setup & Development

To run this portfolio locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Akash-raj-INT/Portfolio.git
   cd Portfolio
   ```

2. **Serve with any local HTTP server**:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node.js / npx
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8000`.
